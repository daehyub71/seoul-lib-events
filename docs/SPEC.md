## 1. 개요

서울도서관 일정 정보 공공데이터(`data/seoul-library-schedule.json`, 1,414건)를 기반으로,
도서관에서 진행된/진행되는 행사를 **지도 중심**으로 탐색할 수 있는 웹페이지를 만든다.
Vercel에 배포한다.

## 3. 기능 요구사항

### 3.1 지도 뷰 (메인)

- **F1. 실제 지도**: Leaflet + OpenStreetMap. 4개 지점 핀, 핀에 현재 필터 기준 행사 건수 뱃지.
- **F2. 핀 인터랙션**: 외부 지점 핀 클릭 → 해당 지점 행사/운영 일정 목록 패널. 서울도서관 핀 클릭 → 층별 실내 뷰로 전환.
- **F3. 층별 실내 뷰**: 1F~4F 단면을 건물 단면 스타일로 표현. 각 공간에 행사 건수 표시, 공간 클릭 시 해당 공간 행사 목록 패널. "지도로 돌아가기" 제공. 층에 못 박을 수 없는 건(자료실 일원·도서관 외부·공간 미상·기타)은 별도 버킷으로 노출.
  (2026-07-18 변경: 표현 방식을 SVG → 시맨틱 HTML 블록으로. 시각 결과는 동일하되 키보드 접근성(N3)과 컴포넌트 테스트 용이성이 나음)

### 3.2 달력 뷰 (부수)

- **F4. 월간 달력**: 월 단위 이동. 하루 단위 행사는 점/칩으로, 기간 행사(시작≠종료)는 가로 바로 표시.
- **F5. 날짜 클릭**: 해당 날짜에 진행 중인 행사 목록 표시 (기간 행사는 기간에 포함된 모든 날짜에 노출).
- **F6. 주 반복 일정**: `period=주` + `period_value=요일`인 일정은 기간 내 해당 요일마다 발생하는 것으로 전개(expand)해 표시.
- **F7. 초기 표시 월**: 데이터가 존재하는 가장 최근 월(2025-05)로 시작. 데이터 없는 월로 이동 시 "일정 없음" 안내.

### 3.3 카드 목록 뷰 (부수)

- **F8. 카드 목록**: 제목, 유형 뱃지, 기간, 시간, 공간, 주최 표시. 최신순 기본 정렬.
- **F9. 페이지네이션 또는 무한 스크롤**: 한 번에 20~30건.

### 3.4 공통 필터/검색

- **F10. 카테고리 탭**: 행사(행사/강연/전시) ↔ 야외공간 운영 분리. 야외공간 탭에서 미운영 일정은 회색 처리.
- **F11. 필터**: 유형(행사/강연/전시), 공간(정규화된 venue), 연도. 필터는 지도/달력/목록 3개 뷰에 공통 적용.
- **F12. 검색**: 제목+내용 텍스트 검색 (클라이언트 사이드).
- **F13. 오늘 기준 상태 뱃지**: 종료 / 진행중 / 예정 구분 표시 (아카이브 성격이므로 필터 기본값은 "전체").

### 3.5 행사 상세

- **F14. 상세 패널(모달 또는 사이드)**: 제목, 유형, 기간·시간·반복, 장소(원문), 주최, 내용 전문, 참고 URL(있을 때만, 새 탭).

## 4. 비기능 요구사항

- **N1. 성능**: 전처리된 데이터(필요 필드만)를 정적 파일로 번들, 초기 로드 후 필터링은 전부 클라이언트에서. 1,414건 규모로 충분.
- **N2. 반응형**: 모바일(1열, 뷰 전환 탭) / 데스크톱(지도+패널 2단) 대응.
- **N3. 접근성**: 키보드 탐색 가능, 시맨틱 마크업, 유형 구분은 색+텍스트 병행.
- **N4. 언어**: 한국어 단일.
- **N5. 배포**: Vercel, `next build` 정적 생성. 서버 런타임 의존 없음.
- **N6. 데이터 갱신**: 원본 JSON 교체 → 전처리 스크립트 재실행 → 재배포 흐름이면 충분 (자동 갱신은 범위 외).
- **N7. 문서화** (2026-07-18 추가, 사용자 요청): 마무리·배포 시 `README.md`(영어)와 `README_KO.md`(한글)를 작성한다. 내용: 프로젝트 소개, 데이터 출처, 주요 기능, 로컬 실행·테스트·빌드 방법, 배포 구조, 데이터 갱신 방법. 두 문서는 상호 링크하며 내용을 일치시킨다.
